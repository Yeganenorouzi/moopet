# راهنمای ویرایش محتوای سایت

هر تغییری در این فایل‌ها بعد از اجرای `npm run build` روی سایت می‌نشیند.
نیازی به دست زدن به کد نیست.

---

## ۱. متن صفحات

**فایل:** `apps/web/src/data/content.json`

تیتر صفحه‌ی اصلی، متن «موپت چیست؟»، سوال‌های پرتکرار، سه قدم، متن صفحه‌ی
درباره ما و تماس، و متن فوتر — همه اینجاست.

```jsonc
"home": {
  "h1Before":    "خدمات حیوانات خانگی را",
  "h1Highlight": "نزدیک خانه‌تان",     // این بخش سبز نمایش داده می‌شود
  "h1After":     "پیدا کنید",
  ...
}
```

### افزودن سوال جدید به پرسش‌های متداول

به آرایه‌ی `home.faq` یک مورد اضافه کنید:

```jsonc
{
  "q": "سوال شما؟",
  "a": "پاسخ شما."
}
```

سوال خودکار هم در صفحه نمایش داده می‌شود و هم به اسکیمای `FAQPage`
اضافه می‌شود (شانس نمایش در نتایج گوگل).

> ⚠️ **فرمت JSON:** هر مقدار باید داخل `"` باشد و بین موارد `,` بیاید.
> آخرین مورد در هر لیست **نباید** کاما داشته باشد. اگر VS Code خط قرمز
> نشان داد، یعنی جایی کاما کم یا اضافه است.

## ۳. اطلاعات مراکز

**فایل:** `apps/web/src/data/listings.json`

```jsonc
{
  "id": "node/123456",
  "name": "کلینیک دامپزشکی نمونه",
  "category": "vet",              // اسلاگ از taxonomy.json
  "neighborhood": "saadat-abad",  // یا null
  "address": "خیابان ...",
  "phone": "02122334455",         // فقط رقم، با صفر شروع شود
  "is24h": false,
  "openingHours": "Mo-Fr 09:00-21:00",
  "lat": 35.77, "lng": 51.37
}
```

### افزودن شماره به مرکزی که ندارد

دنبال `"phone": null` بگردید و شماره را جایگزین کنید:

```jsonc
"phone": "02144556677"
```

فقط رقم بنویسید. `+98` یا فاصله لازم نیست — سایت خودش فرمت نمایشی
(`021 4455 6677`) را می‌سازد.

> ⚠️ **شماره‌ی نادرست از نبودن شماره بدتر است.** فقط شماره‌ای را وارد
> کنید که خودتان تست کرده‌اید.

### حذف یک مرکز

کل بلوک `{ ... }` آن را همراه با کامای قبلش حذف کنید.

## ۴. دسته‌ها و محله‌ها

**فایل:** `apps/web/src/data/taxonomy.json`

```jsonc
{ "slug": "vet", "fa": "دامپزشکی", "faPlural": "دامپزشکی‌ها",
  "kind": "business", "priority": 1 }
```

- `slug` در URL می‌آید (`/vet/`) — **بعد از انتشار سایت عوضش نکنید**،
  چون آدرس صفحه تغییر می‌کند و رتبه‌ی گوگل از بین می‌رود.
- `priority` ترتیب نمایش است؛ ۱ یعنی مهم‌ترین.
- `fa` در عنوان صفحه می‌آید، `faPlural` در تیتر `H1`.

### افزودن محله

```jsonc
{ "slug": "ekbatan", "fa": "اکباتان", "faAlt": "اکباتان",
  "zone": "west", "district": 5, "lat": 35.71, "lng": 51.31 }
```

`faAlt` شکل بدون نیم‌فاصله است (مثل «سعادت آباد» در برابر
«سعادت‌آباد») چون کاربران هر دو شکل را جست‌وجو می‌کنند.

مختصات را از [openstreetmap.org](https://www.openstreetmap.org) بگیرید:
روی نقطه راست‌کلیک → «Show address».

## ۵. مقالات بلاگ

**پوشه:** `apps/web/src/content/blog/`

یک فایل `.md` جدید بسازید — اسم فایل همان آدرس صفحه می‌شود:

```markdown
---
title: عنوان مقاله
description: توضیح کوتاه برای گوگل (حدود ۱۵۰ کاراکتر)
publishedAt: 2026-10-01
cover: /blog/my-post.png
relatedCategory: vet
draft: false
---

متن مقاله با **مارک‌داون**.

## تیتر بخش
```

- `draft: true` یعنی منتشر نشود.
- `relatedCategory` باعث می‌شود پایین مقاله لینک به آن دسته بیاید.
- برای ساخت کاور: `node scripts/make-covers.mjs` (اول در همان فایل
  عنوان و رنگ مقاله را اضافه کنید).

## ۶. رنگ‌ها و فونت

**فایل:** `apps/web/src/styles/global.css`

رنگ‌ها با `oklch` تعریف شده‌اند: `oklch(روشنایی، اشباع، زاویه‌ی رنگ)`

```css
--color-brand-700: oklch(43% 0.08 163);   /* سبز اصلی سایت */
--color-accent-500: oklch(71% 0.158 42);  /* نارنجی دکمه‌ها */
```

برای عوض کردن رنگ برند، فقط عدد سوم (زاویه) را تغییر دهید:
`163` سبز · `250` آبی · `25` قرمز · `300` بنفش

> رنگ اختصاصی هر دسته در `apps/web/src/lib/theme.ts` تعریف شده است.

## وقتی چیزی خراب شد

اگر `npm run build` خطا داد، معمولاً یکی از این‌هاست:

| خطا | علت |
|---|---|
| `Unexpected token` در JSON | کاما کم یا اضافه در `content.json` یا `listings.json` |
| `Cannot read properties of undefined` | کلیدی را از `content.json` حذف کرده‌اید که کد به آن نیاز دارد |
| صفحه‌ی سفید | احتمالاً یک `"` بسته نشده |

**برگرداندن همه‌چیز به آخرین وضعیت سالم:**

```bash
git checkout -- .
```
